Дата: 2026-11-16 · Статус: етапи 1–5 зроблено на Чехії (гілка `feature/route-db`, не злито/не випущено); 6–8 чекають · Репо: `D:\Projects\earth-bus-routes` + `Robitnik/earth-bus-routes-db-eu` (робоча копія `D:\Projects\earth-bus-routes-db`)

## Що сказав гравець
«Треба спарсити всі маршрути в JSON, привести до єдиного стандарту, зберігати в JSON + git raw. Спарсимо ЄС + США, але
збірку з джерел в інтернеті залишимо. Чому: підвантаження займає понад 10 хв, ніхто не буде чекати; ці дані не дуже важкі,
і збирати їх щоразу набагато дорожче; треба мати змогу правити руками.»

## Висновок одним абзацом
Так, робимо. Маршрути заздалегідь збирає **збирач** (на моєму/твоєму ПК, згодом у GitHub Actions) з дампів OSM і фідів GTFS.
Результат у **єдиному форматі `ebr-route/1`** лежить в окремому публічному репо `earth-bus-routes-db`. Служба гравця
бере звідти **плитку** (усі зупинки й лінії квадрата ~25 км, 50–300 КБ) за один запит до raw: секунда замість хвилин.
Ручні правки лежать **окремим шаром** `edits/`, тому перезбірка їх не стирає. Нинішній шлях «наживо» (Overpass, GTFS, OSRM)
лишається запасним: для місць, яких у базі нема, і для свіжих даних.

### 3. Як роздавати з GitHub
- **raw.githubusercontent.com**: у травні 2025 GitHub урізав ліміти для анонімних запитів, серед них — завантаження з raw;
  точних чисел для raw немає (форуми кажуть про 60/год для API, про 429 на raw навіть з токеном). Тому: **не файл на маршрут, а
  плитка** (один запит на квадрат), диск-кеш у службі, і лише незмінні адреси за комітом (`/<sha>/tiles/...`), які можна кешувати
  назавжди.
- **Дзеркало jsDelivr** (`cdn.jsdelivr.net/gh/<repo>@<sha>/...`): той самий файл з CDN, коли raw відповідає 429. Обмеження на
  розмір одного файлу (кажуть, ~20 МБ, не перевірено) — плитки значно менші.
- **Пакунок країни** в Releases (`cz.json.gz`): без задокументованих лімітів трафіку, так само Earth тягне аддони. Опція
  «вся країна офлайн» на потім.

### 4. Ліцензії
- Усе, що з OSM, — похідна база **ODbL**: репо бази під ODbL, атрибуція в кожному файлі (`src`) і в `ATTRIBUTION.md`.
  Код збирача — MIT, як зараз.
- GTFS беремо **лише за списком дозволених** (`sources/feeds.json`): SPDX з відкритого набору (CC0, CC-BY-*, ODbL, ETALAB-2.0,
  NLOD, OGL-UK, DL-DE-BY/ZERO, PDDL) або перевірено руками. У США 811 фідів без ліцензії: спершу лише OSM + 106 з ліцензією +
  ручний список агенцій з відомими умовами.
- CC BY-SA (і подібні) з ODbL не змішувати в одному записі — такі фіди окремими записами з власним `lic`.

## Єдиний стандарт `ebr-route/1`

### Розкладка репо бази
```
earth-bus-routes-db-eu/
  manifest.json                    версія схеми, дата збірки, країни (дата, к-сть ліній, хеш), шлях плиток
  schema/                          JSON Schema: route, tile, stop, edit (перевірка в CI)
  sources/feeds.json               дозволені фіди: id, url, ліцензія SPDX, атрибуція, увімкнено
  data/<cc>/routes/<id>.json       ЗГЕНЕРОВАНО — не правити руками (перезбірка перепише)
  data/<cc>/tiles/<ty>_<tx>.json   ЗГЕНЕРОВАНО — плитка 0,25°: зупинки + короткий список ліній
  edits/<cc>/<id>.json             РУЧНІ ПРАВКИ — накладаються на згенероване при кожній збірці
  edits/<cc>/new/<id>.json         РУЧНІ НОВІ ЛІНІЇ — яких нема в жодному джерелі
  ATTRIBUTION.md  LICENSE (ODbL)
```

### Маршрут (одна лінія в одному напрямку)
```json
{
  "v": 1,
  "id": "cz-360-a7f3",                 // стабільний: країна + номер + хеш кінців; не змінюється між збірками
  "ref": "360", "mode": "bus",
  "name": "360: Police nad Metují – Teplice nad Metují",
  "from": "Police nad Metují, aut.st.", "to": "Teplice nad Metují, žel.st.",
  "operator": "...", "network": "IREDO", "colour": null,
  "stops": [ {"s": "cz:s:1842", "off": 0}, {"s": "cz:s:1843", "off": 240} ],   // id зупинки з плитки + секунди від старту
  "shape": "u{~vHk~ay@...",            // Google polyline 1e-5, спрощена до 2 м; null = будує служба
  "times": {"wd": [355, 425, 785], "sa": [480], "su": [], "valid": "2026-11"},   // хвилини доби, «типовий» день
  "src":  [{"k": "osm", "id": "r6978584"}, {"k": "gtfs", "feed": "cz-jrutil", "id": "641360", "lic": "CIS-JR"}],
  "q":    {"order": "road", "stops_matched": 16, "warn": []}    // якість: звідки порядок, що підозріле
}
```
- **Зупинки в плитках** (`cz:s:1842 → назва, lat, lon, kind: stop|station, platform`): назву чи місце правиш один раз, а не
  в кожній лінії.
- **Розклад як «типовий день»** (будні / субота / неділя), а не календар: для гри цього досить, файл малий, а помісячна
  перезбірка дає маленький дифф. Повний календар (свята, конкретні дати) лишається за живим GTFS, як зараз.
- **Злиття OSM + GTFS**: та сама лінія = той самий номер + ≥ 60 % зупинок у межах 40 м. Дорога з OSM, порядок і час з GTFS
  (логіка вже є в `merge_gtfs`).

### Ручні правки
```json
// edits/cz/cz-360-a7f3.json — лише те, що змінюємо
{"name": "360: Police – Adršpach", "stops.insert": [{"after": "cz:s:1843", "s": "cz:s:9001", "off": 300}],
 "why": "зупинка škola пропущена в OSM", "by": "Robitnik", "date": "2026-11-20"}
// або {"hidden": true, "why": "дубль"}
```
- Збирач: згенероване → накласти `edits/` → перевірити схему → записати. Правка, чий маршрут зник з джерел, лишається у
  звіті «осиротілі правки», а не тихо губиться.
- Правити можна прямо у вебі GitHub (CI перевіряє схему на PR), або з гри: ручний будівник (план 002) отримує кнопку
  «Експорт у базу» → файл `edits/<cc>/new/…json`.

## Що лишається від «живої» збірки
- Overpass/GTFS/OSRM у службі **не видаляємо**. Вони працюють, коли: плитки нема (країна поза базою), гравець увімкнув
  «свіжі дані наживо», або лінія без дороги (`shape: null`) — тоді OSRM, як зараз, з кешем.
- Той самий код розбору (OSM → запис) використовують і збирач, і служба наживо: один стандарт, без двох різних логік.

## Ризики й відкриті питання
1. **Розмір репо**: оцінка 0,6–1,5 ГБ на Європу. Якщо після CZ+DE+FR вийде більше — ділимо репо (eu-west / eu-east) або пакуємо
   плитки в Releases. Вирішуємо на етапі 6 з цифрами.
2. **raw і ліміти**: точних чисел GitHub не дає. Захист: плитки, кеш на диску, незмінні адреси за `sha`, дзеркало jsDelivr,
   запасний шлях наживо.
3. **Ліцензії США**: 811 з 917 фідів без ліцензії — не беремо, поки не перевірено.
4. **Опції аддону**: Earth не приймає понад 16 опцій, а їх уже 16. Перемикач «Джерело: база / база + наживо / наживо» —
   замість однієї наявної (запропоную яку на етапі 5).
5. **Дороги ліній лише з GTFS** без `shapes.txt` і без OSM-відношення лишаються `null`, і першу поїздку служба будує через
   OSRM (секунди–хвилини). Можна потім добудувати їх збирачем зі своїм OSRM по країнах.
6. Збірка Європи вперше — години (завантаження pbf і фідів десятки ГБ). Це робить збирач один раз, не гравець.
