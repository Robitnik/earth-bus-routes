# План: ручний режим — свій маршрут зі станцій (Earth Bus Routes 0.3.0)

Дата: 2026-11-10 · Статус: зроблено 2026-11-10 (A–E, G, F у спрощеному вигляді, H без релізу) · Репо: `D:\Projects\earth-bus-routes` (гілка `main`) · Попередній: `001_bus-routes-addon_2026-11-09.md`

## Задача (слова користувача)
«Прокачати аддон: додати ручний режим, щоб обрати станцію, куди їхати далі; білд маршруту та зупинок.»

Привід: в OSM немає частини реальних ліній (Náchod → Broumov, неповні 300/301/303/305/334/392). Ручний режим дає зібрати такий
рейс самому: станція → наступна станція → … → маршрут по дорогах і зупинки на ньому будуються автоматично.

## Як це виглядає для гравця
1. Меню → нова вкладка **«Свій маршрут»** (поруч із «Лінії поблизу») і **«Мої маршрути»**.
2. Старт = найближча станція (або обрати іншу з поблизу).
3. **«Куди далі?»** — список кандидатів:
   - станції в кільці 0,3–8 км, по напрямку (стрілка-компас) і відстані, автовокзали вгорі;
   - **пошук за назвою** («Broumov») у радіусі ~40 км;
   - міні-карта (SVG без тайлів): станції точками, уже зібраний шлях лінією кольору лінії; клік по точці = обрати.
4. Обрали → дані будують **плече по дорогах** (OSRM) → показуємо км, хв, скільки зупинок по дорозі. Далі знову «Куди далі?»
   від нової станції. «Скасувати останнє», «Завершити тут».
5. **Зупинки на шляху**: режим «усі по дорозі» (зупинки OSM ≤ 25 м від шляху, з правого боку руху) або «тільки обрані»
   (експрес). У списку кожну можна вимкнути/увімкнути.
6. Картка готового маршруту (як у звичайної лінії): номер (ввести, напр. «310»), колір, назва «Náchod ⇒ Broumov», км, час,
   зупинки, згенерований розклад → далі звичний потік: старт зі станції/зупинки, час, HUD, пасажири, бали.
7. **Зберегти** в «Мої маршрути» (переживає перезапуск), видалити, перейменувати. **Зворотний рейс** — будується заново в
   інший бік (односторонні вулиці, зупинки протилежного боку).

### Режим «вільний рейс» (етап F, опційно)
Без плану наперед: їдеш, на кожній зупинці HUD показує 3–4 варіанти «далі» попереду по курсу (клавіша / клік), плече
будується на льоту. Розклад умовний (без запізнень), бали за плавність, пасажирів і обслужені зупинки.

## Рішення (рекомендація; змінюється до «+»)
1. **Шлях по дорогах — OSRM через companion** (новий `/v1/path`): `router.project-osrm.org` (той самий, що вже використовує
   GPS Earth у `server/routing.py`) + дзеркало `routing.openstreetmap.de/routed-car`. Кілька точок одним запитом, кеш на диску.
   Дороги в грі Earth будує з того ж OSM, тож шлях збігається з тим, що під колесами.
   Без мережі/OSRM — запасний шлях: прямі відрізки між станціями (прогрес по зупинках працює, км приблизні) + GPS гри.
2. **Зупинки на шляху — Overpass `around` по ламаній** (новий `/v1/along`): `node[highway=bus_stop|public_transport=platform]
   (around:25, <точки шляху>)`; бік руху рахуємо в Lua (векторний добуток із напрямом шляху). Один запит на маршрут.
3. **Пошук станцій за назвою** — новий `/v1/search?q=&lat=&lon=` (Overpass `name~q,i` у радіусі 40 км, станції + зупинки,
   згруповані як зараз).
4. **Формат маршруту = той самий, що з `osm.parseRoute`** (`stops`, `path`, `length`, `ref`, `colour`, …) + `custom = true`.
   Тоді розклад, пасажири, trip, HUD, бали працюють без змін. Час між зупинками: тривалість OSRM × 1,25 (автобус) + стоянки.
5. **Збереження** — `/settings/earthBusRoutes/myroutes.json` (папка користувача гри), до 50 маршрутів, лише станції-точки
   та налаштування; шлях і зупинки перебудовуються при відкритті (з кешу companion — миттєво).
6. **Межі**: до 25 обраних станцій (OSRM-демо до 100 точок, з запасом), плече ≤ 60 км, весь маршрут ≤ 150 км.
7. Companion → **0.2.0** (нові ендпоінти), мод → **0.3.0**; старий мод зі старим companion — ручний режим показує «онови
   службу даних».

## Етапи

### A. Служба даних (companion 0.2.0)
- `/v1/path?pts=lat,lon;lat,lon;…` → `{points, legs:[{dist,dur}], dist, dur, source:"osrm"|"straight"}`; спрощення ламаної
  (≤ 2000 точок), дзеркала, кеш (ключ = точки з округленням 5 знаків).
- `/v1/along?route=<cache key>` або POST з ламаною → зупинки поруч (слім-формат як `/v1/nearby`).
- `/v1/search?q=&lat=&lon=` → станції/зупинки за назвою.
- `/v1/info` віддає `features: ["path","along","search"]` — мод знає, що вміє служба.
- Тести з фікстурами (записані відповіді OSRM/Overpass Náchod → Broumov), реліз `earth-bus-routes-data` v0.2.0.

### B. Логіка в Lua (чиста, з тестами): `builder.lua`
- Стан конструктора: `waypoints`, `legs`, `stops` (auto/обрані/вимкнені), `mode` (all|express).
- `candidates(stations, from, heading)` — кільце, компас, сортування, автовокзали вгорі, без уже обраних.
- `stopsAlong(path, cum, stops)` — проєкція на шлях, бік руху, відсів дублів (обидва боки, однакові назви < 60 м),
  порядок по `along`; обрані станції завжди входять.
- `toRoute(state)` → об'єкт маршруту як у `osm.parseRoute`; `reverse(state)` → нові waypoints у зворотному порядку.
- `serialize`/`deserialize` для «Моїх маршрутів», валідація старих версій файлу.
- Тести: Náchod → Broumov (фікстури), експрес, вимкнена зупинка, undo, зворотний, прямі відрізки без OSRM.

### C. Оркестрація (`main.lua`) і збереження
- Дії UI: `uiBuildStart`, `uiBuildCandidates`, `uiBuildSearch(q)`, `uiBuildAdd(id)`, `uiBuildUndo`, `uiBuildToggleStop(i)`,
  `uiBuildMode(m)`, `uiBuildFinish`, `uiBuildMeta(ref, colour, name)`, `uiSaveRoute`, `uiOpenSaved(i)`, `uiDeleteSaved(i)`.
- Плечі будуються асинхронно (datasvc черга), у моделі стан «будую…» на конкретному плечі; помилка плеча → запасний
  прямий відрізок + позначка.
- Далі — існуючий шлях: `routeModel` → старт → trip. Зворотний рейс для `custom` = перебудова, а не `reverseOf`.

### D. Інтерфейс
- Вкладки «Лінії поблизу» / «Свій маршрут» / «Мої маршрути».
- Конструктор: ліворуч — ланцюжок обраних станцій (табло-стиль, номер плеча, км/хв, «×» на останній), праворуч — «Куди
  далі?» (пошук + список + міні-карта SVG). Внизу — підсумок і «Готово».
- Екран зупинок: список із перемикачами, бейдж «обрана / по дорозі / вимкнена», режим «усі / експрес».
- Редактор номера й кольору (палітра 8 кольорів + авто з номера як `osm.colorFor`).
- EN + UK у `i18n.js`; перевірка в `tools/preview` (скриншоти в `docs/shots`).

### E. Рейс зі своїм маршрутом
- HUD: бейдж «СВІЙ» поруч із номером; табло автобуса — назва кінцевої як завжди.
- Розклад: тип за довжиною й частотою зупинок (`schedule.kindOf`), інтервали як у звичайних ліній.
- Результат: «Зворотний рейс» / «Інший маршрут» / «Зберегти маршрут» (якщо ще не збережений).

### F. Вільний рейс (опційно, після E)
- Старт без плану; на кожній зупинці (і клавішею `Ctrl+Shift+N`) — HUD-панель 3–4 кандидатів попереду по курсу ≤ 5 км.
- Плече будується за 1–2 с з кешу/OSRM; GPS гри веде до обраної; рейс закінчується клавішею або на автовокзалі.
- Бали без пунктуальності: плавність, обслужені зупинки, пасажири; в кінці можна «Зберегти як маршрут».

### G. Доповнити лінію OSM (опційно)
- На картці неповної OSM-лінії (як 300) — «Доповнити»: копія в конструктор зі станціями лінії, далі додаєш кінцеву
  (Broumov) і зберігаєш як свою. Закриває саме ту прогалину, з якої все почалося.

## Ризики
- **OSRM-демо** обмежує частоту (≈1 запит/с) і може лежати → кеш, дзеркало, прямі відрізки як запас.
- **Overpass повільний** (бачили хвилини) → один запит `along` на маршрут, кеш, показ прогресу; зупинки можна додати й пізніше.
- Профіль OSRM — легковий авто: може повести вулицею, де автобус не їздить. Прийнятно; гравець може додати проміжну станцію,
  щоб «притягнути» шлях.
- Дорога в грі ще не завантажена далеко від гравця — шлях і зупинки рахуються з OSM, а не з графа гри, тож це не заважає;
  GPS Earth веде по ділянках.

## Не входить
- Редагування OSM (надсилання змін) — тільки локальні маршрути.
- Обмін маршрутами між гравцями (можна пізніше: експорт/імпорт JSON).
